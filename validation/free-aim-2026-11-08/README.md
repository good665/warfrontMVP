# TAB 타겟 고정 및 중앙 조준점 제거

사용자 요청대로 TAB 입력 처리, 고정 대상 획득/추적, 고정 버튼과 상태 안내/표시, 중앙 십자 조준점을 제거한다. MMO/컴퓨터전/PvP의 공통 화면에 적용한다. 공격 방향은 카메라의 자유 조준 방향을 그대로 사용한다.

조작 설정에서 사용하지 않는 타겟 버튼 항목을 숨긴다. 기존 저장 설정의 다른 버튼 위치를 보존하기 위해 6개 직렬화 슬롯은 유지하고 기존 슬롯1만 예약 상태로 두며, 실제 배치와 겹침 검사에서는 제외한다. 설정 검사는 실제 공격 버튼으로 갱신한다. 기존 성장·전투 판정·캐릭터·동료·발사체 변경은 없다.

Unity native 검사에서 타겟 획득/추적/HUD 메서드 제거와 자유 조준 유지, 실제 터치 버튼 위치/설정 저장 및 기존 동료·피격·카메라 회귀를 검사한다. 별도 임시 계정으로 실제 컴퓨터 대전 화면을 캡처해 고정 버튼/안내와 중앙 십자가 없는 것을 확인한다.

`results.json`, `checks.log`, `live.log`, `live-ally-arrow.png` 참조. 활성 파일은 원본 해시 확인 및 백업 후 적용한다. 백엔드 변경이나 APK 빌드는 없다.
