# 분대 전투 동작 개선

Blender 4.5.10에서 원본 로우폴리 지휘관과 철제 폭탄을 제작했다. 지휘관은 744개 정점과 16개 뼈의 가중치 스킨이며 Idle, Walk, Attack, Heavy, Dodge, Throw 6개 동작을 포함한다. FBX, PNG 팔레트, URP Lit material, Legacy clips, prefab과 편집 가능한 .blend 및 재생성 Python을 제공한다. Humanoid가 아닌 Generic/Legacy 리그다.

## 전투

- Space/공격 버튼: 145단위(2.9m) 검 공격. 준비 .16초, 활성 .10초, 총 동작 .55초. 피해20. 상대 몸체 반경과 전방 각도·벽 시야를 서버에서 계산한다.
- Q: 210단위 강공격, 준비 .20초, 피해42, 재사용5초.
- Shift: .22초 방향 회피, 속도580단위/초, 재사용3초. 이동 입력이 없으면 바라보는 방향으로 나간다. 회피 중 무적이며 이동 방향을 고정한다.
- E: 최대600단위(12m) 투척, .65초 후 반경150단위(3m) 폭발, 피해30, 재사용8초. 벽 너머 투척·폭발 피해와 아군 피해를 차단한다.

서버 단계로 휘두르기·회피·투척을 샘플링하며 시각 효과와 애니메이션은 서버 위치나 피해를 변경하지 않는다. 이동은 응답 사이에도 걷기를 유지한다. 같은 프레임의 근접 접촉은 양측 후보 수집 후 피해를 적용한다. 기존 RPG 지역의 모델 및 규칙은 유지한다.

## 검사

- 백엔드 전체 `python -m pytest -q`: **231 passed** (34.12초). 거리 경계/뒤쪽/벽, 준비 동작, 중복 적중 방지, 동시 치명타, 양팀 회피 순서, 폭탄 지연·범위·벽·아군 보호·정리 포함.
- Unity6000.3.23f1 native: 스킨 가중치·bindpose, 여섯 동작의 실제 BakeMesh 변형, root motion 없음, URP 팔레트, 서버 단계 샘플링·만료, 폭탄 비행·정리, 기존 던전·피격·컴퓨터전·카메라·타겟 고정 및 기존 회귀 검사 통과. `checks.log` 참조.
- 실제 로컬 API와 별도 임시 계정으로 컴퓨터 대전: 이동/자연 동료 합류/검·강공격/회피/폭탄 투척·비행·폭발/경기 이탈/RPG 성장 보존 확인. 유저 경기 상태나 좌표·HP를 조작하지 않았다. `live.log`, `unity-results.json` 참조.
- `pose-*.png`: 실제 Unity 렌더러의 여섯 동작 자세. `live-*.png`: 실제 컴퓨터 대전.
- 외부 코드 검토에서 지적한 동시 치명타 팀 순서 문제 수정 후 재검토했다.

## 적용과 제한

활성 Unity 파일을 원본 해시로 확인한 뒤 백업하고 검증 파일을 복사한다. 실행 중인 Play는 중지한 뒤 다시 실행하고 새 컴퓨터 대전을 시작한다. 기존 장비/경제/DB 스키마 변경 없음. APK 빌드 및 모바일 실기기 검사는 수행하지 않았다.

모델 원본은 `Assets/ArtSources~/SquadCommander/Commander.blend`에 둔다. `ArtSources~`는 Unity가 자동 임포트하지 않는 원본 보관 폴더이며 실제 게임에서는 `Resources/WarfrontCombat`의 FBX/팔레트/클립/프리팹을 사용한다.
