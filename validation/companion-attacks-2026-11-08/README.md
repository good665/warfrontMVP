# 아군 궁수·수호병 공격 수정

원인: 기존 동료는 서버에서 직접 피해만 주고 공격 동작 상태를 갱신하지 않았다. 궁수도 화살 없이 즉시 피해를 주었으며, 화면에서는 전원이 검·방패를 들고 서 있었다.

## 변경

- 기존 Human 캐릭터 메시와 원래 수호병 검·방패를 유지한다. 새 Blender 캐릭터는 사용하지 않는다.
- 궁수에게 나무 활·시위·화살 장비와 기존 리그용 Bow 동작을 추가한다. .25초 준비 후 발사하고 .65초 동안 당기기·놓기·복귀한다.
- 수호병이 표적을 향해 원래 Attack 동작으로 칼을 휘두른다. .16초 준비 후 사거리·벽 판정으로 한 번 피해를 준다.
- 서버 화살은 발사 때의 표적 위치로 이동한다. 도착 때 실제 위치·생존·아군 여부·벽·회피/보호를 확인하여 피해15를 한 번 적용한다. 시각 화살은 피해를 적용하지 않는다.
- 짧은 비행을 놓치고 완료 이벤트만 받은 경우에도 시각적으로 .12초 따라잡아 표시한다. 같은 이벤트를 반복 수신해도 중복 생성하지 않는다.
- 사거리·시야 이탈 시 추격을 재개하고, 후퇴 또는 리더 사망 시 준비 중 공격을 취소한다. 가까운 벽 뒤 적 때문에 다른 공격 가능한 적을 놓치지 않도록 가시 표적 선택을 보완했다.
- 치유사도 치유 방향과 행동을 표시한다. 양 팀에 동일하게 적용한다.
- 기본 공격 반경 원은 계속 제거 상태다. 폭탄 착지 예고 원도 없애고 실제 폭발 순간 효과만 유지한다.

## 확인

- Backend 전체 `python -m pytest -q`: **252 passed in 37.17s**. 기존 두 추격 회귀 실패를 수정한 최종 결과다.
- Unity6000.3.23f1 native: 양 팀 원본 메시 유지, 활 장비·시위 당기기·놓기, 0.65초 클립, 기존 검 모션, 화살 위치·완료 이벤트·중복 방지·정리, 공격 반경 제거, 던전 호환 검사.
- 기존 캐릭터 복원·피격·컴퓨터전·성장 복원·타겟 고정·카메라 등 회귀 검사.
- 별도 임시 계정의 실제 컴퓨터 대전에서 영웅이 공격하지 않아도 아군 활 동작/검 공격/서버 화살과 상대 동료 공격을 관측했다. 좌표나 HP를 조작하지 않았다. 종료 후 기존 RPG 성장이 유지되는 것도 확인했다.
- `pose-*.png`는 기존 리그의 실제 Unity 자세 렌더이며 `live-*.png`는 실제 컴퓨터 대전 캡처다.
- 외부 코드 검토에서 발견한 후퇴 취소와 완료 화살 표시 문제를 수정하고 재검토했다.

`results.json`, `checks.log`, `live.log`, `installed.json` 참조. 검증 파일은 활성 Assets 원본 해시 확인/백업 후 적용한다. DB 스키마·경제·기존 캐릭터 자산 변경 없음. APK 빌드와 모바일 실기기 검사는 수행하지 않았다.
