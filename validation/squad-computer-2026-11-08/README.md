# 분대전 컴퓨터 상대

분대전 로비에 `컴퓨터와 대전`을 추가했다. 플레이어 자동 매칭/친구 방과 별도이며, 선택 즉시 표준 난이도의 서버 컴퓨터 지휘관과 시작한다. 대전 중 상단에 컴퓨터 모드를 표시한다.

## 동작

- 컴퓨터도 영웅 혼자 출발하고 자기 야영지에서 수호병·궁수·치유사를 모집.
- 같은 능력치·피해·스킬 쿨다운·사거리·부활·12초 동료 충원·본진 파괴 규칙 적용.
- 정상 입력 경로로 이동·공격·방어·저체력 후퇴·회복 후 재공략을 수행.
- 컴퓨터는 방 내부 ID만 사용하며 DB 사용자로 생성하지 않음. 다른 사람이나 자동 매칭 대기열과 격리.
- 사람의 연결 끊김/항복은 기존 규칙으로 처리하고 컴퓨터에는 네트워크 미접속 패배를 적용하지 않음.
- 기존 성장·장비·재화 유지. 서버 연결이 필요하며 오프라인 모드는 아님.

## 최종 검사

모든 구현을 연결한 뒤 마지막 단계에서 검사했다.

- 서버 전체 테스트: 최종 결과 `verification.json` 참고. 컴퓨터 관련 8개 검사는 모집·정상 입력만으로 본진 승리·후퇴·부활·충원·방 격리·인증·DB 계정 미생성·연결 종료를 포함.
- 최초 전체 검사에서 누적 시계의 뺄셈 반올림으로 30초 연결 종료 경계가 실패했다. 만료 시각 비교로 최소 수정하고 29.95초/정확 30초 경계를 검증.
- `checks.log`: 컴퓨터/사람 모드 구분, 서버 상대 표시, 재연결 DTO, 성장 복원과 기존 분대전·본진·타깃·카메라·조작 설정 회귀 검사.
- `live.log`: 실제 한 Unity ApiClient로 인증→즉시 컴퓨터 방 생성→혼자 출발→사람/컴퓨터 양쪽 자연 모집→컴퓨터 이동→재접속 조회→퇴장. 실제 Game 뷰 캡처 및 성장 불변 확인.
- 독립 읽기 전용 코드 검토에서 중요한 결함을 발견하지 못함. 임시 검증 계정은 검사 종료 후 정리.

## 사용과 적용 범위

마을 `분대 PvP · 본진 공략` → `컴퓨터와 대전`. 자동 1대1 매칭과 친구 방은 기존 사람 대전이다.

Unity 검증은 활성 Assets와 같은 소스의 독립 Unity 프로젝트에서 수행하고, 최종 통과본을 백업·원본 해시 확인 후 활성 Assets에 적용한다. 기존 Play가 실행 중이면 정지 후 다시 실행하여 새 코드를 가져온다. 신규 APK·모바일 실기기·외부 배포·대규모 부하 검사는 수행하지 않았다.
