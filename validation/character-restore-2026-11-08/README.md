# 캐릭터 복원 및 공격 반경 표시 제거

사용자 요청에 따라 분대전의 양 팀 캐릭터를 기존 `MiniDungeon/Characters/Human` 모델과 기존 애니메이션으로 복원했다. 새 Blender 캐릭터를 런타임에서 로드하거나 선택하지 않는다. 편집 원본과 사용하지 않는 자산은 보존했다.

바닥의 `Authoritative melee reach` 표시를 제거했다. 검 휘두르기 효과, 회피, 폭탄, 서버의 공격 거리/몸체/시야 판정은 유지한다. 기존 리그에 Heavy/Throw 클립이 없으므로 해당 행동은 기존 Attack 클립으로 표시한다. 기존 피격 효과도 유지한다.

격리된 Unity6000.3.23f1에서 기존 모델 메시 일치, 양팀 공격/강공격/회피/폭탄 모션 호환, 동작 만료 후 idle 복귀, 바닥 공격 범위 오브젝트 미생성을 검사했다. 기존 피격·컴퓨터전·목표 고정·카메라 등 회귀 검사도 실행했다. 실제 컴퓨터 대전에서 별도 임시 계정으로 합류 전/후 화면을 확인했다.

`results.json`, `checks.log`, `live.log`, `solo.png`, `squad.png` 참조. 활성 프로젝트 적용 시 원본 해시 확인 및 백업 후 검증 파일을 복사한다. 백엔드 변경 및 APK 빌드는 없다.
