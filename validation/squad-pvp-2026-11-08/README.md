# 영웅·분대 본진전

선택한 규칙에 맞춰 별도의 실제 플레이어 1대1 PvP를 추가했다. 영웅 혼자 출발하고 자기 야영지에서 수호병·궁수·치유사가 합류한다. 영웅이 쓰러지면 부활하며 적 본진 파괴가 일반 승리 조건이다.

## 사용

- 마을 하단 `분대 PvP · 본진 공략` 또는 `분대 지휘소`로 진입.
- `자동 1 대 1 매칭` 또는 친구 방 생성/코드 참가. 두 사람이 모이면 시작하며 상대를 봇으로 대체하지 않는다.
- WASD/터치 이동, Space/공격, Shift/회피, Q/E 스킬, Tab/타깃 고정.
- 1: 영웅 집결, 2: 집중 공격, 3: 현재 위치 사수, 4: 본진 후퇴. 화면 버튼으로도 명령 가능.
- 집중 공격은 고정한 적을 우선하고, 대상이 없으면 실제 적 본진을 지정.
- 자기 야영지 반경 120에서 동료 세 명 합류. 전사한 동료는 12초 뒤 야영지에서 충원. 영웅은 8초 뒤 부활.
- 본진 HP 2200, 15분 제한. 본진 동시 파괴/시간 초과는 무승부. 항복·30초 연결 끊김은 별도 사유로 표시.
- 동일한 PvP 능력치로 시작하며 기존 RPG 성장·장비·재화에 영향을 주지 않는다.

## 구현·검사

모든 구현을 연결한 뒤 최종 단계에서 검사했다.

- 서버 전체 테스트: **211 passed**, 26.06초. 실제 입력만으로 야영지 모집→적 본진 파괴→승리를 완주하는 검사 포함.
- `checks.log`: 실제 Mini Dungeon 본진/야영지 모델, 정확한 서버 좌표, 파괴·재경기 초기화, 본진의 카메라 가림 처리, 대기/활성/종료 상태, 대기 JSON null, 원래 프로필 복원, 세션 만료 복구 검사. 기존 타깃·카메라·장비·설정·임무 회귀 검사도 연결하여 실행.
- `live.log`: 두 개의 실제 Unity ApiClient가 로컬 FastAPI에 인증→친구 방 생성/참가→혼자 출발→양쪽 동료 모집→위치 사수/본진 집중 공격→항복 결과를 처리. 서버 스냅샷을 실제 게임 장면/HUD로 렌더.
- 본진 파괴 승리는 서버의 실제 입력 완주 검사로, 실시간 두 클라이언트의 결과 화면은 항복 종료로 각각 구분해 검증했다.
- 독립 검토에서 찾은 결과 화면 커서 재잠금과 동료 모서리 정지를 수정. 충돌 반경을 반영하는 가시성 그래프 경로 탐색 및 회귀 테스트 추가.
- 실제 화면 검사 후 동료 대형을 분산하고, 공격 사거리 안 흔들림·스폰 본진 카메라 가림·먼 적 이름 겹침을 수정.
- 첫 실시간 검사에서 재현한 Unity JsonUtility의 `world:null` 빈 객체 생성을 방 상태 기준으로 정상화. 이후 검사 중 임시 계정을 일찍 정리한 검증 순서 경합도 바로잡아 종료 후에만 정리한다.
