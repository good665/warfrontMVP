# 플레이어 피격 효과

사용자가 몹에게 맞는 느낌을 요청해 기존 얇은 테두리와 공통 타격음을 강화했다.

- 서버의 자기 HP 감소에 붉은 가장자리 그라데이션과 짧은 옅은 화면 틴트, 실제 감소량의 `피격 -숫자`, 충격 표시를 연결.

- 약 0.24초의 작은 카메라 위치/롤 충격. 서버 조작·위치·조준 계산은 변경하지 않음. 바닥 높이 제한과 기존 벽 여유 거리를 보존.
- 공격음과 다른 약 0.22초의 낮은 피격음을 추가. 기존 효과음 켜기/음량 설정 사용, 공격음과 독립 재생 제한, 클립 재사용·종료 시 해제.

- 첫 접속, 같은 상태 재수신, 다른 플레이어 피해, 회복, 지역/사용자 변경, 장비 최대 HP 감소에는 가짜 피격을 만들지 않음. 최대 HP 조정과 실제 피해가 함께 있어도 실제 남은 손실을 표시.
