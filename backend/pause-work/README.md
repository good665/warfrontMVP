# ESC 일시정지

실제 Unity 프로젝트 `C:/Users/good6/WarfrontMVP/Assets/script`에 적용.

- 컴퓨터 부대전: 횟수 제한 없이 ESC 정지 / 재개.
- 1:1 부대전: 플레이어별 경기당 정지 3회. 재개는 횟수를 차감하지 않음.
- 서버가 양쪽 전투, 쿨다운, 생산, 경기 시간을 정지. 정지 요청자만 재개 가능.
- 정지 중에도 상태 조회와 연결 종료 감지, 항복은 동작.
- `POST /v1/squad/{code}/pause`에 `{"paused": true/false}` 전달.
- 서버 재시도는 같은 상태를 요청하므로 횟수를 중복 차감하지 않음.
- 백엔드와 Unity 클라이언트를 함께 업데이트해야 함. 실행 중인 서버는 재시작 필요.

원본 Unity 파일은 `.backup` 파일로 보존. `manifest.json`은 적용 전 원본의 SHA256.
Unity C# 컴파일과 백엔드 테스트로 검증. Editor 실제 화면 검증은 창 캡처가 다른 앱을 반환하여 수행하지 못함.
