# 전투 개선 설계

## 5층 맵 설계
나는 1층 또는 5층에서 시작해
내가 1층이면 다른 유저,컴퓨터는 5층 시작
내가 5층이면 컴퓨터,유저는 1층 시작

1층에서 2층으로 가는 방법은 포탈로 가는 방법으로 구현해줘.
포탈은 맵의 끝 오른쪽 그리고 왼쪽 포탈로 이동가능해
포탈을 타면 내 캐릭터는 사라지는 연출이 되고 내가 1층이면 1층에서 사라졌다가, 2층으로 부드럽게 나타나는 효과로 올라가
반대로 내가 5층이면 아래층으로 가지는걸로 해줘
3층 가운데는 용을 구현해주고, 용은 보스몹으로, 죽이면 3분뒤에 다시 리젠되, 용을죽이면 랜덤 옵션 1가지가 부여되, 옵션은 추천해줘

## 3*3 아이템 개편
생산,건설,연구 - 기능 삭제해
대신에 내 본진 가운데, 양끝에서 미니언들이 계속 생산되서 적기지로 자동으로 처들어가는걸로 바꿔줘. 생산되는건 30초에 한번씩으로 해줘
해당 3*3은 놔두고, 1층부터 랜덤 구역에 몬스터 기지 3개가 있어,몬스터는 2명은 쫄병,1명은 중간보스급으로 넣어주고 그 중간보스를 죽이면 대결에 필요한 아이템1개를 드랍해. 만약 컴퓨터나 유저가 나와 똑같은 몬스터를 때리고 있으면, 대미지를 많이 넣은 사람이 아이템을 가질수 있게 해
아이템은 게임이 종료되면 사라지게 해줘. 아이템은 랜덤 옵션으로 해줘.

## 캐릭터 추가
기존 캐릭터는 삭제해주고
12간지 캐릭터를 만들어줘, 각각에 캐릭터마다 Q스킬, E필살기를 구현해줘 
전체 캐릭 전부 점프는 스페이스바로 구현해줘

## 메인화면 장비 삭제
장비 화면까지 옵션을 추가해서 게임에 적용시키는게 생각보다 재미가 없을거같은데, 계속 적용하는게 맞는지, 아니면 삭제를 해야할지 추천해줘

## 사용자 확정 사항 (2026-11-14)

- 전투 개편과 기존 플레이어 캐릭터 교체는 컴퓨터 대전·사람 간 본진 대전에 한정한다.
- 공동 사냥터, 고대 유적 원정, 탐험 관문, 장비 보관실은 삭제한다.
- 층 사이 포탈은 양방향으로 이동할 수 있다.
- 몬스터 기지는 각 층에 3개씩, 총 15개 배치한다. 각 기지는 쫄병 2명과 중간보스 1명으로 구성하며 재생성하지 않는다.
- 기존 생산·건설·연구 기능을 제거하고 3×3 영역은 경기 전용 아이템 9칸 인벤토리로 변경한다.
- 중간보스 아이템과 용 처치 보상은 개인에게 지급한다. 중간보스 아이템 소유자는 누적 피해량으로 결정한다.
- Space 점프는 연출용이며 실제 회피·장애물 통과 효과를 주지 않는다.
- 새 플레이어 캐릭터는 12간지 동물 캐릭터로 제작한다. 미니언은 현재 외형을 유지한다.

### 세로 맵·포탈 추가 확정 및 반영

- 맵은 가로보다 세로가 긴 형태(2400×3600)로 바꾼다.
- 포탈은 세로 위·아래 끝 벽의 출입구에 붙여 배치한다. 위 끝은 위층, 아래 끝은 아래층으로 연결한다.
- 위층으로 이동하면 해당 층 아래 끝에 도착하고, 아래층으로 이동하면 해당 층 위 끝에 도착한다.
- 도착한 포탈은 이전 장소로 돌아가는 용도다. 같은 자리에서 계속 전진할 수 없고 다음 층으로 가려면 반대편 포탈까지 전장을 횡단해야 한다.
- 미니언·컴퓨터 이동, 본진·몬스터 배치, 용 중앙 위치, 카메라·경계도 세로 맵에 맞춘다.

### 아직 사용자 확정 사항이 아닌 구현 제안

- 기존 서버 권한 본진 대전과 Unity 클라이언트를 확장하고, 캐릭터도 서버에서 선택·스킬·피해량을 검증한다.
- 삭제 모드는 메뉴·관문·진입 경로와 해당 API 제공을 종료하되 기존 계정·저장 데이터는 삭제하지 않는다.
- 용 보상 소유자도 누적 피해량으로 결정하며, 동률이면 먼저 해당 피해량에 도달한 개인에게 지급한다.
- 아이템은 자동 획득·능력치 적용하고, 9칸이 가득 차면 기존 아이템과 교체를 선택한다.
- 기본 공격은 좌클릭, Q는 일반 스킬, E는 필살기, Space는 연출용 점프로 구성한다.
