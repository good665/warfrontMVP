# 새 전장 교체 설계

## 확정 범위
기존 5층 전투를 128×128 단일 격자 전장으로 교체한다. 1:1은 2명, 2:2는 팀당 2명으로 플레이한다. 30초 자동 미니언 생성은 제거한다. 클릭·드래그·Shift·더블 클릭 선택, Ctrl+1~9 부대 저장 및 호출, 부대 키 연속 입력 시 카메라 이동, 1인칭 집결 핑을 구현한다.

## 검토한 방식
- 기존 전투 교체: 기존 로비에서 새 전장에 진입하며 서버의 전투 규칙과 클라이언트 표시를 함께 전환한다. 사용자가 선택한 방식이다.
- 별도 모드 추가: 기존 5층 게임도 유지할 수 있지만 모드별 UI와 규칙을 추가 관리해야 한다. 선택하지 않았다.

## 구현 기본값 제안
아래는 사용자가 별도로 지정하지 않은 항목의 제안이다.
- 1:1은 대각선 두 본진, 2:2는 같은 팀을 인접한 두 본진에 배치한다. 모든 시작 지점의 자원 배치와 진출 거리는 대칭으로 맞춘다.
- 플레이어마다 영웅 1명과 초기 호위 병력을 지급한다. 초기 호위는 근접 3명, 원거리 2명으로 시작한다. 자동 충원은 없으며 자원 채집·유닛 생산 경제는 이번 범위에 포함하지 않는다. 자원은 배치 좌표와 표시를 제공한다.
- 적 팀의 모든 본진 파괴 시 승리한다. 영웅은 본진이 살아 있는 동안 부활하고, 호위 병력은 사망하면 제거한다. 본진이 파괴되어도 남은 병력은 지휘할 수 있다.
- 각 플레이어는 자신의 병력을 지휘한다. 동맹 병력은 정보 확인만 가능하며 상대 플레이어의 명령을 덮어쓰지 않는다. 핑 위치는 팀원에게 표시하고 자신의 AI 병력이 집결한다.
- 기본 시점은 전체 맵을 담는 탑뷰다. 줌·화면 이동을 지원하고 Tab으로 영웅 1인칭 시점을 전환한다. RTS 좌클릭은 선택, 우클릭은 이동·공격 명령에 사용한다. 1인칭은 기존 이동·공격 조작을 사용하고 G로 집결 핑을 보낸다.
- 기존 12종 영웅 모델과 기술을 재사용한다. 이번 변경은 전장과 지휘 방식 교체이며, 스프라이트 기반 2D 아트 전환은 별도 작업이다.
- 1:1과 2:2 대기열·방 정원을 분리한다. 2:2는 4명이 모이면 시작하고 플레이어별 팀·본진·소유 유닛을 명시적으로 관리한다. 컴퓨터 대전은 모드에 맞춰 빈 자리를 AI로 채운다.
- 접속이 끊긴 플레이어는 기존 30초 유예 동안 복귀할 수 있다. 이후 해당 플레이어의 병력은 방어 상태가 되며, 팀 전체가 이탈하면 패배한다.

## 구현 구조
서버가 맵 좌표, 팀, 소유권, 이동·피해·승패를 판정한다. 기존 2인 방의 인덱스를 팀으로 쓰는 로직을 명시적 팀 배정으로 바꾼다. 선택 유닛 ID를 명령에 포함하고 소유권·생존 여부·시야를 검증한다. 기존 5층 이동과 포탈 UI, 자동 생성 카운트다운을 새 전장 흐름에서 제거한다.

Unity는 활성 프로젝트 Assets/script를 수정한다. 격자는 논리 데이터로 관리하고 바닥은 청크 메시로 그려 16,384개 오브젝트 생성을 피한다. 현재 RenderTexture 전투 카메라에 맞춰 포인터를 변환하며 선택용 Collider와 유닛 식별 컴포넌트를 추가한다. 드래그 UI는 Canvas에 표시하고 Raycast Target을 끈다. 죽거나 교체된 유닛은 선택 목록·부대·효과 캐시에서 제거한다.

## 검증
서버: 모드별 정원, 동맹 판정, 권한 없는 명령 거절, 자동 생성 제거, 승패·이탈·재접속, 컴퓨터 대전 및 기존 API 회귀 검사.
Unity: 컴파일, 실제 전투 진입, 단일·다중·Shift·동종 선택, 부대 저장·호출·카메라 이동, 시점 전환·핑, UI 클릭 차단, 사망·캐릭터 교체 후 참조 정리 확인.
통합: 1:1 두 클라이언트 및 2:2 네 클라이언트로 팀 배정·명령·승패 일치 확인. 모바일 터치 전용 지휘 UI는 이번 PC 키보드·마우스 명세와 별도다.

## 상태
사용자 확정: 기존 전투 교체, 1:1 및 2:2 지원.
사용자가 “구현해줘”로 위 기본값을 승인했다. 런타임 구현과 검증을 진행한다.
