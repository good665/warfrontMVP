# 전투 개선 및 맵 설계

## 대전 모드 (사용자 확정)

- 1:1: 플레이어 2명이 서로 다른 두 팀으로 대전한다.
- 2:2: 플레이어 4명이 팀당 2명으로 대전한다. 4인 개인전은 포함하지 않는다.
- 두 모드 모두 128×128 격자 전장을 사용한다.

### 배치 및 연동 제안 (미확정)

- 1:1은 대각선 두 본진을 사용하고 나머지 두 시작 본진은 비활성화한다.
- 2:2는 네 본진을 모두 사용하고, 같은 팀은 인접한 두 모퉁이에 배치한다.
- 유닛의 소유 플레이어와 팀을 별도로 식별한다. 동맹 여부와 명령 권한은 서버에서 검증한다.
- 현재 서버 방은 2인 입장 시 시작하므로, 모드별 정원·팀 배정·시작 조건을 확장해야 한다.
- 기존 5층 전투를 새 128×128 전장으로 교체한다. 별도 RTS 모드로 추가하지 않는다. (사용자 확정)

## 맵 설계
유니티로 128x128 타일 크기의 격자형 전장 맵을 생성하는 스크립트를 작성해 줘.

Grid 구조를 기반으로 가로 128칸, 세로 128칸 크기의 맵 보드(Floor)를 생성할 것.

스타크래프트 투혼 맵처럼 4인용 대칭 구조로 설계하고, 맵 네 모퉁이에 각각 플레이어/적 본진(Base) 영역과 자원 배치 좌표를 미리 지정해 줘.

카메라가 이 128x128 맵 전체를 한눈에 담을 수 있도록 탑뷰(Top-down) 시점의 기본 카메라 위치와 조명을 세팅해 줘.

## 전투 설계
현재 미니언들이 30초에 자동 생성되는 부분을 삭제시켜줘.

유니티에서 스타크래프트 스타일의 RTS 유닛 선택 시스템(단일 클릭 + 마우스 드래그 박스 다중 선택)을 구현해 줘.

단일 클릭 선택: 마우스 좌클릭 시 Camera.main.ScreenPointToRay로 Raycast를 쏴서 PlayerTeam 태그(또는 레이어)를 가진 유닛 1개를 선택하고, 기존 선택은 해제해 줘. (Shift 키를 누른 상태면 기존 선택에 추가/토글)

드래그 박스(Marquee) 다중 선택: 마우스를 누른 채 일정 거리 이상 드래그하면 화면(Canvas UI RectTransform)에 반투명 초록색 선택 박스를 그려줘. 마우스를 떼면 씬에 있는 모든 아군 유닛의 월드 좌표를 Camera.main.WorldToScreenPoint로 변환해 드래그 사각형 영역 안에 들어온 유닛들을 전부 선택 리스트에 담아줘.

시각 피드백 및 팀 구분: 적군(EnemyTeam)은 드래그 다중 선택에서 제외하고 단일 클릭으로만 정보 확인이 가능하게 해줘. 선택된 아군 유닛 발밑에는 초록색 원형 선택 링(Selection Circle)이 활성화되게 만들어 줘.

부대 지정(Ctrl + 숫자): "선택된 유닛 리스트를 Ctrl + 1~9 키로 부대 지정하고, 숫자 키를 누르면 해당 부대가 선택되며 두 번 연속 누르면 카메라가 그 부대 위치로 이동하게 해줘."

더블 클릭 전체 선택: "같은 종류의 아군 유닛을 더블 클릭하면 현재 화면(Viewport) 안에 보이는 동일한 타입의 아군 유닛을 모두 한 번에 선택하게 해줘."

## 1인칭 지휘 / 집결 핑 시스템
1인칭 플레이어가 맵을 이동하다가 특정 지점을 바라보고 키를 누르면, 아군 팀원(AI 유닛)들이 해당 지점으로 합류하는 집결(Rally Point / Ping) 시스템을 유니티 C#으로 구현해 줘.



## 확인해줘야할 내용
에디터에서 아래 3가지가 누락되면 클릭/드래그가 먹통이 될 수 있습니다.

유닛 콜라이더(Collider) 유무: 단일 클릭(Raycast)이 인식되려면 유닛 프리팹에 Capsule Collider나 Box Collider가 반드시 붙어 있어야 합니다.

팀 구분 태그/레이어: 코드에서 지정한 팀 식별자(예: Tag = "PlayerTeam" 또는 TeamID == 0)가 실제 아군 유닛 오브젝트에 동일하게 적용되어 있는지 확인하세요.

UI Canvas 설정: 드래그 박스가 화면에 그려지려면 씬에 Canvas가 있어야 하며, 드래그 박스 이미지의 Raycast Target 옵션은 반드시 체크 해제되어야 마우스 클릭을 가로채지 않습니다.
