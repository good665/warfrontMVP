# Squad headquarters PvP implementation plan

> **For agentic workers:** Parallel independent implementation domains, inline integration. Preserve user's implementation-first / final-checks-only preference.

**Goal:** Real human 1v1, solo start, camp recruitment, three commanded companions and enemy headquarters destruction.

**Architecture:** Separate authoritative squad simulation and matchmaking API; Unity reuses existing MMO camera/controls/presentation with dedicated squad HUD/network adapter.

**Tech Stack:** FastAPI/Python, C# Unity 6000.3.23f1 Input System and existing Mini Dungeon meshes.

**Spec:** docs/superpowers/specs/2026-11-08-squad-pvp-design.md

## Review focus

- No companions before own camp; opponent cannot recruit your squad; lost companions replenish only with camp return and cooldown.
- Focus/hold/retreat commands are server-validated and retry idempotent; disconnect stops movement.
- Heroes respawn, headquarters do not; exact winner/draw transitions, no post-finish damage.
- Simultaneous requests cannot join two rooms or attack other rooms; finished matches recover over reconnect.
- All existing PvE UI actions are disabled in squad matches; settings/touch/target lock reflect the new battlefield.
