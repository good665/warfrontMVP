# Sideline 기본 12간지 프리팹 이전 계획

**Goal:** 사용자가 지정한 claude-sideline의 기본 외형 12종을 Unity 프리팹으로 가져오고 현재 RTS 영웅에 연결한다.
**Architecture:** 원본 models.js에서 body/leg 기본 파츠만 추출한다. Unity Editor 빌더로 단일 스킨드 메시·색상 팔레트·파트 본과 애니메이션·프리팹을 생성한다. Resources/SidelineZodiac를 우선 로드하고 기존 Zodiac 에셋은 보존한다.
**Tech stack:** Python 데이터 변환, Unity 6000.3.23f1/URP, Generic part-bone rig 및 legacy Animation.

## 제약
원본 프로젝트를 수정하지 않는다. Unity 코드와 에셋은 활성 WarfrontMVP/Assets에만 적용한다. 5단계 업그레이드·회전 후광·왕관 장식은 제외한다. sheep→goat ID 대응을 유지한다. 서버 능력·피해·좌표·미니언은 변경하지 않는다.

- [x] 재현 가능한 Python 추출기와 Unity 빌더 작성. 각 기본 파츠의 원본 피벗과 형태 유지, 파트당 1본 가중치로 원본의 단단한 파츠 움직임 보존.
- [x] Idle/Walk/Attack/Heavy/Dodge/Bow/Throw 7개 클립 생성. 외부 루트 이동 없이 내부 Rig만 애니메이션. 뱀은 원본 부유 동작 유지.

## 결정
원본은 스킨 리그가 아닌 파트 피벗 애니메이션이다. 파트당 100% 가중치를 갖는 Generic 본으로 원본 외형을 보존한다. 팔레트 PNG는 원본 단색 재질을 묶은 변환 데이터이며 새 그림을 생성하지 않는다. 공격/회피는 원본에 전용 클립이 없어 현재 게임에 맞게 내부 Rig 동작으로 보완한다.
