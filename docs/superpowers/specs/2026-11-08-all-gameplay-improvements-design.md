# 우선순위 전체 개선

사용자 승인 범위: 이미 완료한 수동 타깃 고정을 보존하고 추천한 2~6번을 모두 구현한다. 사용자가 명시한 순서에 따라 모든 구현과 연결을 끝낸 뒤 마지막 단계에서 검사한다. 구현 전 테스트 실행 및 단계별 Unity 검사 흐름은 이번 요청에서 사용하지 않는다.

- 전투: 서버가 공격 예고 시간을 갖고 공격 위치를 고정한다. 플레이어는 예고 원을 보고 이동/회피할 수 있다. 적 피격 경직·타격음·피격 강조는 실제 서버 결과를 따른다.
- 임무: 기존 처치 임무와 데이터를 보존하면서 정예 처치·탐색·보스 임무를 순환한다. 진행·보상은 SQL에 저장하고 서버만 판정한다. 추가 JSON 컬럼은 데이터 삭제 없이 명시적으로 이행한다.
- 장비: 현재 장비 대비 공격력/최대 HP 변화와 장비 획득 알림을 보여준다.
- 길찾기: 미니맵에 자신/방향/적/파티원/장애물과 실제 임무 목표를 표시한다. 세계에 존재하지 않는 입구 좌표를 만들지 않고 지역 진입 버튼을 제공한다.
- 조작 설정: 마우스/터치 감도, 상하 반전, 기본 카메라 거리, 타격음 켜기/음량, 이동/타깃/공격/회피/스킬 버튼별 크기와 위치를 저장한다. 화면 안으로 제한하고 버튼 중첩 저장을 차단한다. 취소는 기존 값을 유지하고 기본값 복원이 가능하다.

선택한 방식: 기존 Unity/서버 흐름을 확장하며 새 메뉴·패널을 기존 게임에 연결한다. 독립 샘플 화면이나 클라이언트 임시 보상 방식은 실제 플레이 요구를 충족하지 못한다.

Unity 활성 Assets를 기준으로 기존 임시 검증 프로젝트에서 구현한 뒤, 최종 검사·백업·해시 비교 후 적용한다. 서버는 로컬 검증 환경에서 이행 및 통합 실행을 확인하며 외부 운영 서버에 배포하지 않는다. 신규 APK/모바일 실기기 검증 결과는 별도로 밝힌다.
