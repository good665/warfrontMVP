# 분대전 컴퓨터 상대

사용자 요청: 기존 분대 PvP에서 컴퓨터와 싸우는 모드도 선택할 수 있게 한다. 기본값은 서버가 조종하는 표준 난이도 컴퓨터 지휘관 1명이다. 로비에 `컴퓨터와 대전`을 추가하고 선택 즉시 시작한다. 실제 플레이어 매칭/친구 방은 계속 별도로 제공한다.

컴퓨터 역시 영웅 한 명으로 출발하고 자기 야영지에서 동일한 동료 셋을 모집한다. 같은 이동·사거리·쿨다운·피해·본진 HP·부활·충원 규칙을 따른다. 야영지 모집/충원, 위협 방어, 영웅 체력에 따른 후퇴, 적 본진 공략을 선택하며 서버의 정상 입력 경로를 사용한다. 숨겨진 능력치 보너스나 즉시 소환은 없다.

연결된 서버는 필요하다. 컴퓨터는 DB에 실제 사용자로 생성하지 않고 방 내부 전용 ID로만 존재한다. 사람 대기열에 들어가거나 다른 사람이 컴퓨터 방에 참가하지 않는다. 컴퓨터는 네트워크 접속 종료 판정에서 제외하며 사람의 접속 종료/항복/본진 파괴/무승부는 기존 규칙을 따른다. 기존 RPG 성장·장비·재화는 변경하지 않는다.

선택한 구현은 기존 서버 시뮬레이션에 컴퓨터 입력 생성기와 명시적인 computer 방 생성 API를 추가하는 방식이다. 클라이언트에 별도 전투 시뮬레이션을 두면 기존 서버 규칙과 어긋나므로 채택하지 않는다. 난이도 선택·오프라인 모드·새 APK/외부 배포는 이번 요청에 포함하지 않는다.

사용자가 요청한 구현 후 최종 검사 순서를 유지한다. 임시 Unity Assets에서 구현하고 서버 전체 테스트·컴퓨터 행동/인증/방 격리·Unity 로비/HUD·실제 한 클라이언트 연동을 마지막에 검사한 뒤 활성 Assets를 백업·해시 확인하여 적용한다.
