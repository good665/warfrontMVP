# 플레이어 피격 효과 강화

사용자 요청: 몹에게 맞을 때 맞는 효과를 추가한다. 현재 자기 HP 감소 감지는 있으나 얇은 9px 테두리와 공격/피격 공통 효과음으로 표현이 약하다.

확정 구현: 서버가 보낸 자기 HP 감소에 붉은 가장자리/짧은 옅은 틴트, 실제 감소량 숫자, 캐릭터 상체 움찔과 피격 강조, 작은 위치/롤 카메라 충격, 별도 둔탁한 피격음을 연결한다. 반응은 0.25~0.4초 이내에 감쇠하며 전체 화면 흰색 섬광이나 게임 정지는 사용하지 않는다. 기존 음량/효과음 설정을 따른다.

캐릭터·카메라 변화는 표시만 변경한다. 서버 위치·HP·조준 방향·공격/회피/스킬·재화는 바꾸지 않는다. 최초 접속/다른 지역/다른 플레이어/회복/같은 스냅샷 재수신에는 가짜 피격을 만들지 않는다. 귀환/재접속 초기화 시 잔여 효과를 정리한다. 같은 표시 경로를 쓰는 분대전에서도 자기 HP 감소에 적용한다.

기존 피격 감지와 장면 렌더러를 확장하며 활성 Assets를 기준으로 임시 Unity Assets에 구현한다. 전체 구현 후 마지막에 HP 감소·중복 방지·초기화·짧은 실제 렌더·기존 회귀 검사를 실행하고 검증본을 백업·해시 확인 후 적용한다. 새 APK나 모바일 실기기 검사는 범위 밖이다.
