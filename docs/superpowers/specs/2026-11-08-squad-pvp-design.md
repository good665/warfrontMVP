# 영웅·분대 본진 파괴 PvP

대화에서 선택한 규칙: 영웅을 직접 조작한다. 경기 시작에는 혼자이며, 전장의 지정 지점에서 동료가 합류한다. 다른 플레이어도 자기 분대를 지휘한다. 영웅은 부활하며 상대 본진을 파괴하면 승리한다. 첫 버전은 제안한 1대1, 영웅+최대3명, 수호병/궁수/치유사, 집결/집중공격/위치사수/후퇴 명령이다.

기존 PvP는 점수/점령 경기이고 MMO는 공동 사냥이라 승리·공격 대상·세션 규칙이 다르다. 선택한 방식은 별도 squad API/매칭과 서버 시뮬레이션을 추가하고 기존 3인칭 입력·카메라·타깃·피격·조작 설정·모델을 재사용하는 것이다. 기존 점수 경기나 사냥터를 교체하는 방식은 기존 기능을 잃어 제외했다.

구현자 기본값(초기 밸런스): 3600×2400 대칭 전장, 양측 본진 (250,1200)/(3350,1200), 자기 야영지 (800,1200)/(2800,1200), 거리120 이내 도착 시 동료 세 명이 자동 합류. 영웅160 HP, 본진2200 HP, 영웅8초 부활, 본진 방어 공격과 자기 본진 주변 회복. 동료는 전사 시 12초 뒤 자기 야영지에서 영웅이 다시 모으면 충원한다. 전투 중 즉시 무제한 충원하지 않는다. 각자 동료는 경기 전용이며 RPG 장비·레벨로 능력치 우위를 얻지 않는 동일 조건이다.

집결은 영웅 추종, 집중공격은 선택한 적 또는 적 본진, 위치사수는 명령 시점 영웅 위치 방어, 후퇴는 자기 본진 이동. 영웅 사망 중에는 동료가 본진으로 후퇴한다. 본진 공격·동료 AI·피해·치유·합류·재합류·승패는 모두 서버가 판정한다. 명령은 시퀀스로 중복 방지하며 입력은 0.35초에 만료한다.

마을에 분대 PvP 진입을 추가한다. 자동1대1매칭과 친구 방 코드 생성/참가를 제공하며 사람이 두 명이어야 시작한다. 양쪽 본진 HP, 분대 상태/명령, 야영지·목표 위치, 영웅 부활, 경기 결과를 표시한다. 항복/접속종료 판정은 명시적인 별도 종료 사유이며 본진 파괴로 위장하지 않는다. 15분까지 본진을 파괴하지 못하면 무승부이고, 같은 틱 동시 본진 파괴도 무승부다.

첫 버전은 비랭크 경기로 기존 재화·스태미나·MMO 성장 데이터를 변경하지 않는다. 별도의 과금/영구 병력 성장/대규모 전투/외부 배포/새 APK는 범위 밖이다. 모든 구현을 먼저 마친 뒤 최종 단계에서 서버 전체 테스트, Unity 회귀/실제 화면과 두 클라이언트 연동을 검사한다. 활성 Assets는 검사 후 백업과 해시 확인으로 적용한다.
