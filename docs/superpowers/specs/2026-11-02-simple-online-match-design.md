# 단순 온라인 자동 매칭

요청: 군사 기지 로비에서 서버 접속 설정을 숨긴다. 온라인 지휘본부는 1:1·3:3 버튼과 로비 복귀만 보여준다. 모드 버튼을 누르면 사람을 자동 매칭하고, 대기 중 취소하고 로비로 돌아갈 수 있어야 한다.

기존 quick-match와 waiting-only leave API를 유지한다. 역할 선택은 제거하고 기본 돌격을 사용한다. 대기 화면은 모드·모인 인원·경과 시간·취소 버튼을 표시한다. 요청 전송·폴링 중에도 취소 의도를 기억하고 요청이 끝나면 서버에서 대기를 취소한다. 서버가 이미 시작한 경기는 취소로 포기시키지 않고 전투 화면으로 이동한다. 네트워크 응답이 유실되면 current-room으로 서버 상태를 확인한다.

로비의 설정 버튼은 모든 빌드에서 제거한다. 출시 빌드는 초기 접속 설정 화면과 오류 화면의 개발용 설정 버튼을 노출하지 않는다. 개발 빌드의 오류 화면에서는 설정 도구를 유지한다. 운영 HTTPS 주소·인증·상시 배포와 실제 iOS 빌드는 별도 출시 준비이며 이번 변경에서 임의로 구성하지 않는다.

검증: Unity 기존 검사·backend 테스트·Android APK 빌드·단말에서 두 모드 선택, 대기 취소, 인원이 모였을 때 자동 시작을 확인한다. 서버 waiting-only 취소 경합 검사를 함께 실행한다.
