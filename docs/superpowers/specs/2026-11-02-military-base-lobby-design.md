# WARFRONT 군사 기지 로비

사용자가 선택한 방향은 참고 이미지의 건물 중심 픽셀 아트 로비를 WARFRONT 군사 기지로 바꾸는 것이다. 상단에 프로필·체력·다이아·랭킹, 중앙에 기능별 건물, 하단에 보조 게임과 온라인 대전 진입을 둔다.

훈련장은 기존 AI 1:1, 분대 막사는 AI 3:3, 지휘본부는 온라인 1:1/3:3, 격납고는 정비소, 전적 게시판은 랭킹을 연다. 돌격·폭탄·PvE·서버 설정·테스트 체력 회복 기능은 계속 접근 가능해야 한다. 생성 배경에는 글자를 넣지 않고 실제 UI로 한국어 버튼과 실시간 자원을 표시한다.

기존 Unity IMGUI와 안전 영역·1280×720 기준 레이아웃을 유지한다. 시작 연결 중과 오류 화면에도 기지 배경을 표시한다. 서버 API, 경기 규칙, 보상은 변경하지 않는다. 활성 프로젝트 Assets/script에 별도 LobbyView.cs와 Assets/Resources에 배경을 추가한다. 기존 코드와 자산은 변경 전 백업한다.

검증은 기존 Unity 검사, Android 개발 APK 빌드와 설치, 실제 단말의 버튼 진입·복귀·온라인 메뉴·자원 표시·오류 화면으로 한다. 두 물리 기기와 6명 실제 플레이는 장비와 인원 확보 전 완료로 보고하지 않는다.
