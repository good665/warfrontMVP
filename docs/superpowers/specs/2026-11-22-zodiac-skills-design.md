# 캐릭터 Q/E 모션 및 이펙트

사용자 요청: 12종 캐릭터 스킬과 필살기의 어색한 모션을 개선하고 PNG 및 FBX 자산을 실제 플레이에 연결한다. 후속 지시: 원숭이 Q는 전방 찌르기, E는 크게 휘두르기.

기존 서버 판정, 피해량, 이동, 사거리를 보존한다. 서버가 내보내는 character/skill/kind/radius/fx/fy/floor/id를 시각 효과의 근거로 사용한다. 모델과 기본 공격, 서버 통합 코드는 보존한다.

## Approaches
- PNG만 표시: 제작은 간단하지만 손과 무기가 움직이지 않아 요청을 충족하지 못한다.
- 기존 리그용 FBX 모션 + FBX 입체 소품 + 투명 PNG 효과: 채택. 캐릭터를 교체하지 않고 동작과 효과를 함께 연결한다.
- 전체 캐릭터 리깅 교체: 기존 스킨 및 장비 연결에 위험이 커 제외한다.

모션은 준비/공격/복귀가 있는 제자리 Legacy 클립으로 제작한다. 원숭이는 양손 봉 자세, Q 전방 찌르기, E 수평 대회전. 나머지는 돌진/발톱/포효/시전/방어 등 기존 스킬 성격을 따른다. 기본 공격과 동시 재생하지 않는다.

효과는 서버 이벤트별 한 번만 재생한다. 방향 공격, 광역, 보호막, 회복을 구분하고 층 변경/필드 전환 시 정리한다. PNG 아틀라스를 URP 투명 셰이더로 사용한다. FBX와 blend 및 생성 스크립트를 보존한다.

검증: 24개 스킬 자산/모션, 리그 변형, 루트 이동, 이벤트 중복/층 필터/정리, Unity 렌더 미리보기, 기존 관련 검사. 실제 게임 서버 피해 시점은 즉시 판정이므로 연출이 피해를 새로 만들거나 늦추지 않는다.
