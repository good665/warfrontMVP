# 주간 시즌 미니게임 제안

## 요청과 운영 방향

온라인 지휘본부를 작전 훈련본부로 바꾸고 사격장·드론 보급·암호 해독을 넣는다. 사람 간 1:1·3:3 자동 매칭은 하단 온라인 대전 출격에서 유지한다.

준비된 세 게임을 한국 시간 월요일 00:00마다 사격장 → 드론 보급 → 암호 해독 순서로 바꾼다. 주간 교체는 서버 일정으로 처리해 매주 앱 업데이트를 요구하지 않는다. 시즌은 한 주 단위이며 한국 시간의 ISO 주차로 표시한다. 구현 기준 주는 2026-11-02 월요일이다.

확정: 이번 주 게임 하나만 플레이 가능하며 한국 시간 월요일 00:00에 다음 게임으로 교체한다. 사용자 요청에 따라 세 게임을 순환한다. 출시 화면에는 비활성 주간 게임의 연습 진입을 제공하지 않는다.

## 제안하는 첫 구현 범위

세 게임은 각 45초짜리 무료 1인 플레이로 시작한다. 참가비와 새 재화 보상은 추가하지 않고, 결과·정확도 등과 기기별 주간 개인 최고 기록을 표시한다. 글로벌 순위·시즌 보상·서버가 판정하는 경쟁 점수는 후속 기능으로 둔다. 기존 대전·생존 게임의 체력과 보상은 유지한다.

- 지휘관 사격장: 등장하는 적 표적을 터치한다. 연속 명중으로 점수를 쌓고 아군 표적을 누르면 감점·연속 명중 초기화. 결과에 명중 수·오사 수·정확도 표시.
- 드론 보급 작전: 한 손가락 드래그로 이동한다. 보급품을 가져와 기지에 전달한다. 장애물·위험 구역 충돌은 잠시 이동 정지와 보급품 손실을 발생시킨다. 결과에 전달 수·충돌 수 표시.
- 통신 암호 해독: 네 개 신호 버튼이 켜지는 순서를 보고 그대로 입력한다. 성공하면 순서 길이를 늘린다. 오답은 시간 페널티 후 새 순서를 제시한다. 신호 시연 중에는 입력하지 않는다. 결과에 성공 단계·오답 수 표시.

점수 공식·표적 간격·드론 속도·암호 표시 간격은 구현자가 초기 값을 정하고 문서에 기록한다. 세 게임의 점수는 서로 비교하는 공용 랭킹으로 표시하지 않는다.

## 일정과 기록의 경계

서버가 현재 시즌·시작/종료 UTC·이번 주 게임·다음 게임을 내려준다. Unity는 서버 시간과 로컬 단조 시간으로 남은 시간을 표시한다. 휴대폰 시계나 시간대 변경으로 공식 주간 게임을 바꾸지 않는다.

게임 도중 주가 바뀌어도 45초 플레이는 끝낼 수 있다. 시작할 때의 시즌에 결과를 기록하고 훈련본부로 돌아왔을 때 새 시즌을 조회한다. 주간 기록 키는 서버·플레이어·시즌·게임으로 분리해 다른 계정 기록이 섞이지 않게 한다.

네트워크 문제로 새 주간 일정을 확인할 수 없으면 주간 게임 시작을 잠시 막고 재시도를 제공한다. 앱 백그라운드 전환은 일시정지하고 복귀 시 재개 또는 훈련본부 복귀를 제공한다.

## 구현 경계

활성 Unity 프로젝트 C:/Users/good6/WarfrontMVP/Assets 아래에 순수 게임 규칙과 화면·입력을 분리한다. 기존 안전 영역과 1280×720 디자인 좌표, New Input System을 사용한다. 로비 그림과 버튼 시스템을 재사용한다.

백엔드는 주간 일정 계산과 읽기 API를 추가한다. 주간 전환용 DB 마이그레이션은 필요하지 않다. 이번 단계의 기록은 기기별 개인 기록이며 서버 보상·온라인 랭킹을 변경하지 않는다.

## 검증 기준

- backend: 일요일 23:59:59 / 월요일 00:00 한국 시간 경계, UTC 변환, 연말 ISO 주차, 3주 순환, 응답의 현재·다음 게임 일치.
- 게임 규칙: 적 명중·아군 오사·연속 명중, 드론 전달·충돌·경계, 암호 시연 중 입력 무시·성공·오답, 45초 종료와 종료 후 입력 무시.
- 앱: 훈련본부 진입, 세 게임의 실제 터치 입력, 결과·다시하기·복귀, 주간/연습 표시, 일시정지·앱 복귀, 기존 온라인 출격 유지.
- Android 개발 APK 빌드와 휴대폰 한 대 확인. 실제 iOS 빌드와 장기 성능은 별도 검증으로 기록한다.
