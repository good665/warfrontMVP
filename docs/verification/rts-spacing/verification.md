# 미니언 겹침 수정 검증

- 원인: 미니언의 경로·집결 목표가 같지만 서버에 캐릭터 간 분리 처리가 없어 같은 좌표로 수렴했다.
- 변경: 살아 있는 미니언끼리 및 영웅과 약 80 서버 단위 간격을 유지한다. 영웅은 밀어내지 않는다. 공간 셀로 인접 병력만 비교한다.
- 이동: 영웅 앞에 막힌 미니언은 접선 방향으로 돌아가며, 맵 경계 밖을 향하는 회피 방향 대신 안쪽 방향을 선택한다. 영웅이 점유한 중간 웨이포인트는 도달 가능한 접점에서 통과 처리한다.
- 기존 이동/공격 명령, 소유권, 목적 좌표는 보존한다. 정지 명령은 자발적 이동을 중단하며 주변 몸체에 의해 겹침 해소 위치 보정은 받을 수 있다.
- 재현 테스트: 같은 좌표의 5/10명, 맵 모서리, 2웨이브 집결, 영웅이 경유지/경로를 막는 상황, 각 지도 경계 회피, 이동/집결/교전 회귀를 검증한다.
- 집결 2웨이브 10명 시뮬레이션에서 최소 중심 간격 79.951 서버 단위 확인.
- 활성 Unity Editor에서 별도 서버 스냅샷을 RtsChecks로 렌더링해 선택·레이캐스트·소유권·표시 검사 통과. 실행 중이던 사용자의 일시정지 경기는 그대로 유지했다. overview.png는 해당 독립 스냅샷 렌더이다.
- HTTP 승리 테스트는 적 거점에 명시적인 focus 명령을 내리도록 변경했다. 몸체 간격 도입 후 균형 잡힌 공격 이동 전투의 승패는 고정되지 않으므로 거점 파괴 응답 검증 대상을 명확히 했다.

최종 검증: backend에서 python -m pytest -q 실행 결과 291 passed in 43.65s. 독립 코드 리뷰에서 경계 회피 원본 재현과 간격 테스트 13개 통과를 확인했고 추가 중요 문제는 발견하지 않았다.
