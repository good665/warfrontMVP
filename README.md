# 전쟁 스토리: WARFRONT — Unity MVP

현재 개발 대상 Unity 프로젝트는 `C:\Users\good6\WarfrontMVP`이며, 코드는 해당 프로젝트의 `Assets/script/`에 있습니다. 이 워크스페이스의 `Assets/Scripts/`는 이전 로컬 MVP 사본입니다. 아래 로컬 MVP 설명과 구분해 사용하세요.

## 사람끼리 1:1 / 3:3 온라인 친선전

로비의 **온라인 1:1 / 3:3 대전**에서 크기와 역할을 선택합니다. **빠른 대전**은 같은 서버의 대기자를 모아 자동 시작하고, **새 방 만들기 / 코드로 입장**은 친구와 6자리 코드를 공유해 만납니다. 1:1은 두 명, 3:3은 여섯 명이 필요하며 AI로 빈자리를 채우지 않습니다. 전투·체력·승패·보상은 서버가 계산하고, 난이도 단계는 서버 전투 시간 기준 **60초마다 1씩 상승**합니다.

실행 방법과 검증 결과는 [온라인 실행 안내](ONLINE_PLAY.md)를 참조하세요. 인터넷 친구 테스트용 임시 HTTPS 실행 방법은 [테스트 서버 안내](FRIEND_TEST_SERVER.md)에 있습니다. 코드 대전과 빠른 대전은 랭킹 변동 없는 친선전입니다. 상시 클라우드 서버 배포는 별도 단계입니다.

## 1:1 / 3:3 AI 거점 대전

로비의 **1:1 거점 대전** 또는 **3:3 분대 대전**에서 역할을 선택해 출전합니다. 1:1은 플레이어 대 AI로 420점 선취·최대 15분, 3:3은 플레이어와 아군 AI 2명 대 적 AI 3명으로 600점 선취·최대 20분입니다. 제한 시간 종료 시 점수가 높은 팀이 승리하며, 동점은 무승부입니다. 처치로도 소량의 팀 점수를 얻고, 전사 후에는 부활 대기와 보호 시간이 적용됩니다.

| 역할 | 기본 특성 | Q 스킬 | E 스킬 |
| --- | --- | --- | --- |
| 돌격 | HP 120, 빠른 공격 | 5초 연사 강화 | 주변 폭발 |
| 수호 | HP 160 | 주변 아군 보호막 | 충격파·밀치기 |
| 지원 | HP 100 | 주변 아군 회복 | 주변 아군 이동 가속 |

- PC: WASD/방향키 이동, 마우스 조준·왼쪽 버튼 공격, Space 자동 조준 공격, Shift 회피, Q/E 스킬. 자동 조준은 사거리 내에서 엄폐물에 가리지 않고 부활 보호 중이 아닌 적을 우선하며, 화면 조준점으로 방향을 확인할 수 있습니다.
- 모바일: 왼쪽 패드 이동과 하단 공격·회피·스킬 버튼. 여러 손가락으로 이동·공격·스킬을 동시에 입력할 수 있고, 패드에서 시작한 손가락은 밖으로 움직여도 이동을 계속 제어합니다. 실제 기기 조작감 검증은 별도로 필요합니다.
- 3:3 명령: `1` 거점 공격, `2` 거점 주변 방어, `3` 플레이어 주변 집결. 화면 버튼으로도 선택할 수 있습니다.
- 엄폐물은 이동과 투사체를 막고, 초록 보급 상자는 체력을 회복한 뒤 30초 후 재생성됩니다.
- HUD에 팀 점수, 단계·다음 단계 시간, HP·스킬 재사용 시간, 미니맵과 처치 알림을 표시합니다. 결과창에는 처치·전사·피해량·회복량·거점 기여 시간을 표시합니다.

전투 진행 시간 기준으로 1분마다 단계가 상승합니다. 1단계는 기본 전투, 2단계부터 중립 적과 경고 후 발동하는 위험 구역이 등장하며, 3단계부터 정예 적과 회피를 사용하는 AI가 등장합니다. 이후 웨이브 빈도와 위험 패턴이 상한 내에서 강화됩니다. 일시정지와 재개 카운트다운은 전투 진행 시간에 포함되지 않습니다. 기존 돌격·폭탄 생존 모드 주기는 유지합니다.

출전 시 체력 10을 사용합니다. AI 연습은 랭킹·기존 PvP 승패 기록을 변경하지 않고, 승리 시 1:1은 다이아 3개, 3:3은 5개를 받습니다. 패배·무승부·포기는 승리 보상이 없습니다. AI 모드는 기존 `arena1`/`arena3` API를 사용하고, 사람 간 대전은 별도 온라인 방 API를 사용합니다. 데이터베이스 컬럼 변경은 없습니다. AI 결과는 기존 클라이언트 보고 방식이며, 온라인 결과는 서버 판정 방식입니다.

자동 검사: Unity 메뉴 **Warfront → Run Arena Checks**. **Warfront → Run Balance Sample**은 같은 시드의 AI 자동 대전 12개로 경기 길이를 재측정합니다. 시뮬레이션은 `ArenaSimulation.cs`, 화면·효과음은 `ArenaView.cs`, 다중 터치 판정은 `ArenaControls.cs`, 기존 흐름 연결은 `GameBootstrap.cs`에 나누었습니다. 측정 전후 비교와 검증 한계는 `BALANCE_REPORT.md`에 기록했습니다.

## 활성 Unity 프로젝트: 전투 결과 복구

활성 프로젝트는 로그인, 체력, 전투 정산, 랭킹과 보상을 FastAPI에 연결합니다. 전투 종료 시 결과를 먼저 로컬에 보관하고, 서버 확인 후 삭제합니다. 서버 응답이 없으면 결과 화면의 **전투 결과 다시 확인**으로 같은 전투를 재시도합니다. 확인 대기 중에는 새 전투를 시작할 수 없습니다.

보관한 결과는 서버 주소와 플레이어 ID별로 구분하며, 앱을 다시 실행한 뒤 로그인하면 복원됩니다. 서버가 이미 처리했다면 최신 플레이어 상태를 조회해 확인하고, 보상을 로컬에서 다시 지급하지 않습니다. 만료되었거나 서버에 없는 전투는 안내 후 종료합니다. 이 복구는 전투가 끝나 결과를 저장한 이후에 적용되며, 플레이 도중 앱을 종료한 전투의 재개는 지원하지 않습니다.

수동 검증 순서:

1. 전투 종료 직전에 네트워크 또는 개발 서버를 중단하고, 결과 전송 대기 화면이 표시되는지 확인합니다.
2. 연결을 복구한 뒤 **전투 결과 다시 확인**을 눌러 보상과 체력이 한 번만 반영되는지 확인합니다.
3. 결과 전송 대기 상태에서 Play를 종료하고 다시 시작해 미전송 결과가 복원되는지 확인합니다.
4. 서버가 결과를 처리했지만 응답을 받지 못한 경우, 재시도 시 **서버 처리 완료**와 최신 상태가 표시되는지 확인합니다.

## 일시정지와 전투 포기

AI·생존 모드에서 전투 중 **일시정지 [ESC]** 또는 Esc 키를 누르면 이동, 공격, 적 AI, 매칭 준비 타이머와 생존 기록이 멈춥니다. **계속하기**를 누르면 3초 뒤 재개됩니다. 앱이 포커스를 잃거나 백그라운드로 이동해도 자동으로 일시정지합니다. 서버의 전투 만료 시간은 정지하지 않습니다. 온라인에서는 Esc가 메뉴만 열며 서버 경기는 계속 진행됩니다.

**전투 포기 → 종료하고 정산**은 모드별 서버 API를 사용합니다. AI 친선전은 승리 보상 없이 종료하고, 이전 PvP는 패배와 점수 차감, PvE는 실패, 생존 모드는 일시정지 전까지의 기록으로 정산합니다. 온라인에서는 포기한 참가자의 팀이 패배합니다. 사용한 체력은 반환하지 않습니다.

에디터 검증 항목: 각 모드에서 정지 중 체력·적 위치·생존 시간이 고정되는지, 공격 버튼과 Space가 작동하지 않는지, 재개 3초 동안 게임이 멈추는지, 포기 확인의 **돌아가기**가 정산을 호출하지 않는지, **종료하고 정산**이 한 번만 반영되는지 확인합니다. 여기서 체력 고정은 전투 HP를 의미하며, 서버의 계정 체력 자연 회복은 계속됩니다.

## 이전 로컬 MVP

Unity 6 기준의 모바일 게임 MVP입니다. 전투와 보상은 `PlayerPrefs`에 로컬 저장되며, 로비의 **서버 계정** 화면에서 FastAPI 게스트 로그인과 서버 플레이어 상태 조회를 사용할 수 있습니다.

## 포함 기능

- 체력: 최대 100 / 한 판에 10 소모 / 실제 시간 1시간당 5 회복
- 돌격 게임: 날아오는 탄환과 박쥐를 피하는 생존 게임
- 폭탄 피하기: 시간이 지날수록 큰 폭탄을 피하는 생존 게임
- 1:1 랜덤 매칭: 2초 매칭 연출 후 AI 지휘관과 실시간 공격 대결, 승리 +100점·다이아 3개, 패배 -100점
- 다이아 보상: 미니게임 15초 생존마다 1개, PvP 승리 시 3개
- 로컬 랭킹 및 전적
- 일일 랭킹 보상 수령과 다이아 기반 지휘관 강화(정비소)
- 광고 체력 회복: 하루 최대 5회, 회당 체력 10 회복 (현재는 테스트 보상 버튼)
- PvE 작전: 최고 스테이지 다음 작전에 도전하고, 클리어 시 다이아 획득

## 실행

1. Unity Hub에서 이 폴더를 Unity 6 프로젝트로 엽니다.
2. 빈 씬을 생성합니다.
3. Hierarchy에서 빈 GameObject를 만들고 이름을 `GameBootstrap`으로 정합니다.
4. `Assets/Scripts/GameBootstrap.cs`를 GameObject에 붙입니다.
5. Play 버튼을 누릅니다. PC에서는 `A/D` 또는 좌우 화살표로 움직이며, 모바일에서는 화면을 드래그합니다. 1:1 대전은 공격 버튼 또는 `Space`로 공격합니다.

화면은 16:9 가로형(기준 1280×720)으로 자동 확대·축소됩니다. Unity Game 탭의 Aspect를 `16:9`로 두면 가장 자연스럽게 확인할 수 있습니다.

입력은 새 Unity Input System에 맞춰 구현했습니다. `GameData`는 추후 FastAPI API 호출로 대체할 저장소 경계입니다. Photon Fusion 매칭을 붙일 때는 `StartRandomMatch()`와 `UpdateMatchmaking()`을 실제 룸 매칭 및 결과 콜백으로 교체하면 됩니다.

## 서버 계정 연결

1. `backend/`에서 `uvicorn app.main:app --reload`로 서버를 실행합니다.
2. Unity의 `GameBootstrap` 컴포넌트에서 `Api Base Url`을 설정합니다. 에디터 기본값은 `http://localhost:8000`입니다.
3. Play 후 로비에서 **서버 계정**을 누르고 이름을 입력한 뒤 **게스트 로그인**을 선택합니다.
4. 로그인 후 **서버 상태 새로고침**으로 체력, 다이아, 점수, 전적, 전투력과 최고 작전을 조회합니다. 이름은 최초 가입에 사용되며 이후 로그인에서는 기존 계정 이름을 유지합니다.

게스트 식별자는 설치별 무작위 값으로 생성해 `PlayerPrefs`에 유지합니다. 식별자를 삭제하면 새 계정으로 가입합니다. JWT는 메모리에만 보관하고 실행 시 다시 로그인합니다. 만료된 세션은 조회 시 한 번 재로그인하며, 연결 실패 시 버튼으로 재시도할 수 있습니다. 서버 데이터와 로컬 연습 데이터는 서로 덮어쓰지 않습니다.

실제 모바일 기기에서 테스트할 때는 서버를 `uvicorn app.main:app --reload --host 0.0.0.0`으로 실행하고, `Api Base Url`을 같은 네트워크의 개발 PC 주소로 설정합니다. 기기의 `localhost`는 PC를 가리키지 않습니다. 모바일 빌드에서는 HTTPS 서버 주소 사용을 권장합니다. WebGL은 배포 출처를 서버의 `ALLOWED_ORIGINS`에 추가해야 합니다.
